# 专升本政策查询服务网

面向专科在读学生的专升本（普通高校专升本）政策查询与三年规划工具。全部内容依据教育部高校学生司及省级教育考试院**公开发布的文件**整理，每条结论标注文件名称、文号或发布机构，便于逐条核对原文。

单文件页面，不依赖任何外部资源与网络请求，克隆后双击 `index.html` 即可使用。

## 内容结构

| 栏目 | 说明 |
| --- | --- |
| 政策解读 | 四条升学路径对照：普通高校专升本（全日制）、自学考试、成人高考、开放大学 |
| 资格自测 | 按年级 / 学制 / 身份 / 目标给出主推路径与 30 天内待办事项，含退役士兵、技能大赛获奖、三支一扶分支 |
| 省级文件 | 14 个省级行政区细则：报名时间、考试时间、科目分值、志愿规则、免试政策、报考限制、原文出处 |
| 专业对照 | 19 个专科大类可报考的本科门类；每个大类附「专业课考什么」科目表（按报考方向列出多数院校笔试科目）、建议先修的专科课程，以及报考风险提示 |
| 专业课学习 | 32 门常考专业课：常见题型、高频考点（按科目核心章节与常见题型归纳）、三轮学习动作、易错点；配三轮复习通用节奏 |
| 时间安排 | 选入学年份与学制，倒推三年备考时间表，标注报名、考试、毕业证三类硬节点 |
| 风险提示 | 十条文件明文条款对应的常见失误 |
| 文件来源 | 15 组出处，可直接链接到省级考试机构官网 |
| 官方渠道 | 教育部、阳光高考平台、学信网及 14 省教育考试院（招生考试院）官方网址一览，逐省标注主要用途与报名平台 |

## 官方渠道（对应页面「09 官方渠道」栏目）

页面里那张表的完整内容，也在这里列一份，方便直接点开核对。报名、缴费、志愿填报、成绩与录取查询只在这些渠道进行。

核对方法：进入省教育考试院官网后，在“通知公告”“普通专升本”“招生考试”栏目查找文件名含“专升本考试招生工作”的当年文件；文件名之外，还要看文号与发布日期。院校层面的专业课考纲、参考书、加试要求，只在各校招生章程与教务处网站公布，需逐校查看。若网址无法访问，请从省教育厅官网的“直属单位”入口进入，避免误入仿冒站点。

## 数据基准

- 基准年度：**2026 年**（最近一个完整招录年度），更新至 2026 年 11 月。
- 国家层面母文件：教育部高校学生司《关于做好 2026 年普通高等学校专升本考试招生工作的通知》（教学司函〔2025〕53 号）。
- 已录入细则：山东、江苏、浙江、广东、安徽、福建、河南、湖北、湖南、四川、河北、陕西、江西、重庆，共 14 省（市）；其余省份在页面内提供三步自查路径，未编造链接。

## 免责声明

本项目为**个人整理的政策信息汇编工具，非政府部门官方网站**，不提供培训、代报名服务，不作任何录取承诺。政策每年调整，具体报名时间、考试科目、招生计划以报考当年官方最新文件为准。涉及报名与录取的决定，请以省教育考试院与招生院校公布的文件为唯一依据。
